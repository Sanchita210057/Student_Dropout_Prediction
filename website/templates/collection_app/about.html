ABOUT PROJECT

Student support through risk assessment

A university project demonstrating a saved, calibrated Logistic Regression ensemble and practical student-support workflows.

Project purpose

This system helps identify students at higher dropout risk so institutions can consider timely support actions.

Datasets

UCI: {{ dataset_counts.uci }} resolved student records
Bangladesh: {{ dataset_counts.bangladesh }} university student responses

The datasets train separate model components; they are not pooled as one training set.

Assessment tools

  • Individual student assessment
  • CSV and Excel batch analysis
  • Risk indicators and support guidance
  • Teacher-owned collections and edit audit
  • No automatic model retraining

Interpretation

The model estimates reported current dropout-status patterns. Running and Passed are grouped as non-dropout, but Running does not establish eventual graduation. It has not been prospectively validated to predict future dropout.
